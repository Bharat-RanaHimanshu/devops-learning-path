## Study protocol

1. **One lesson at a time.** Each lesson lives in `lessons/NN-slug/` with `index.html` (interactive, standalone), `notes.md` (cheat sheet) and `my-notes.md` (written by the learner, never pre-filled). From Lesson 02 on, each lesson also has a `lab/` folder.
2. **A lesson is done only when** the learner has worked through it, every doubt is answered and logged in [DOUBTS.md](DOUBTS.md), and the learner explicitly confirms they're ready. The next lesson never starts before that confirmation.
3. **Update this file at the end of every study session:** lesson status, current lesson, next step, and a line in the session log.
4. **Keep the course consistent:** new lesson pages reuse the colors, fonts and component styles from Lesson 01's `index.html`.
5. **Verify facts that change:** AWS services, prices, limits and tool versions are checked against current sources before they're taught, and anything unverified is flagged.
6. **Cloud safety:** AWS labs start only after the Lesson 08 guardrails (MFA, no root access keys, billing alarm) are in place. Secrets never go into the repo.

## Conventions

- Commits are authored as the repository owner, with plain messages: a short imperative subject and an optional body. No trailers.
